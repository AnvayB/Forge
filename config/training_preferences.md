# Preferred Split

Examples:

- Upper / Lower
- Arnold
- PPL

I want to maintain this routine:

5 day routine:
- Sunday: Lower
- Monday: Rest (or light cardio)
- Tuesday: Chest + Back + front delts
- Wednesday: Arms (bicep, tricep, side delts)
- Thursday: Legs + rear delts
- Friday: Rest (or light cardio)
- Saturday: Upper

Cardio done every other day
