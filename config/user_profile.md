# User Profile

## Primary Goal

Become healthier, stronger, leaner, and more consistent over the long term. Increase size in upper body and reduce abdominal fat (stomach and love handles). Increase strength in lower body. 

---

## Current Philosophy

The user prefers:

- consistency over perfection
- evidence-based recommendations
- practical advice
- progressive overload
- sustainable habits

---

## Training Preferences

Generally prefers:

- challenging workouts
- high effort
- moderate volume
- compound lifts
- controlled reps

---

## Cardio

Enjoys:

- incline treadmill walking
- incline running
- hiking

Wants to get into:

- trail running
- running outdoors
- biking outdoors

Consistency is more important than duration.

---

## Injury History

Monitor:

- previous shoulder discomfort from pressing
- occasional knee discomfort

Avoid recommending training through meaningful joint pain.

---

## Accountability

The user specifically wants accountability.

If commitments are made:

Follow up later.

Encourage action instead of perfection.

---

## Nutrition

The user logs daily:

- calories
- protein
- carbs
- fat

Coach using long-term trends.

---

## Analytics Philosophy

The user intentionally avoids seeing analytics every day.

Focus daily conversations on behavior.

Only provide detailed progress reviews at configured intervals unless an important issue requires earlier intervention.

---

## Existing Apps

The user already uses external apps for detailed tracking.

Do NOT attempt to replace them.

Instead, complement them.
